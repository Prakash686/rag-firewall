# Team Contributions

This document outlines the individual responsibilities and contributions of the project team members.

---

## Person 1 – Backend

### Primary Responsibility

Person 1 was responsible for the **backend development and implementation of the RAG Firewall**.

### Contributions

- Designed and implemented the backend application
- Developed the RAG processing pipeline
- Implemented document ingestion and processing
- Worked on document sanitization and preprocessing
- Implemented retrieval-related backend functionality
- Developed prompt injection detection functionality
- Implemented backend security and firewall logic
- Integrated the LLM with the backend pipeline
- Developed backend APIs using FastAPI
- Handled backend configuration and integration
- Tested and debugged backend components
- Worked on integrating the different security components into the RAG pipeline

### Main Area

**Backend / RAG Pipeline / Security Layer / API**

---

## Person 2 – Frontend

### Primary Responsibility

Person 2 was responsible for the **frontend development and user interface of the RAG Firewall**.

### Contributions

- Designed and developed the frontend interface
- Implemented the user-facing RAG Firewall interface
- Developed frontend components and pages
- Integrated the frontend with the backend APIs
- Implemented user interaction flows
- Displayed RAG responses and security-related information
- Worked on the presentation of detected or blocked content
- Implemented frontend state and API handling
- Tested and debugged frontend functionality
- Improved the usability and presentation of the application

### Main Area

**Frontend / UI / API Integration / User Experience**

---

## Collaboration

Although responsibilities were divided between backend and frontend development, both team members collaborated on the integration and testing of the complete RAG Firewall application.

The backend and frontend components were developed as interconnected parts of the same system, with the frontend consuming the APIs and security results provided by the backend.
